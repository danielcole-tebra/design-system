# Archive

This folder holds the gated multi-agent workflow that ran here from August to September 2026: the batch scripts that opened and closed schema records (`batch-scripts/`), the loose scan and generator scripts from August (`loose-scripts/`), 81 dated copies of the aggregate schema (`schema-backups/`), the validator, contract generator, record gate, risk lock, runner and their self-tests (`scripts/`), the generated contract, manifest, rules, execution policy and check catalog (`workflow/`), the generated indexes (`indexes/`), the aggregate `design-system-schema.json`, the per-batch `plan.md`, `inventory.json`, `execution.json` and `handoff.json` artifacts (`figma-export/`, paths preserved), the instruction files it ran under (`CLAUDE-2026-09-12.md`, `AGENTS.md`, `OPERATORS.md`, `clinerules`, `copilot-instructions.md`), the frozen handoffs (`HANDOFF.md`, `CHAT-HANDOFF.md`), and the discovery, build and method documents from August (`discovery/`).

It was retired on 2026-09-12 because no gate ever stopped a bad Figma write, while every session read 200 to 400 KB of contract, manifest, indexes and plans before its first action. Nothing in this folder runs anymore: the scripts expect paths that no longer exist and a record store that is now closed. History lives in the record files under `../records/`; the live record is `../LOG.md`, with open findings in `../FLAGS.md`.
