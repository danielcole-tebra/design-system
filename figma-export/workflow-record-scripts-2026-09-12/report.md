## The hard stop

| Stage | Helper | Refused before any write when |
|---|---|---|
| apply | `apply(spec)` → `openRecord` | body lacks `_status` (IN PROGRESS), `date`, `workstream`, `risk` (tier in low/medium/high/human-decision plus a quote at `risk.operatorQuote`, `risk.approval.quote` or `operatorContinuationQuote`), `scope`, `report`, `stopCondition`, `nextAction`; a string still carries a TODO marker; `createdBy` missing; the provisional envelope exceeds the ceiling |
| checkpoint | `checkpoint(id, mutate)` → `finalizeRecord` | the result leaves IN PROGRESS; a TODO marker; the envelope exceeds the ceiling |
| close | `close(id, mutate)` → `finalizeRecord` | the status is not terminal (`DONE` by default); `outcome` or `validation` missing; `report` does not exist on disk; `risk.tier` differs from the opened record (rule 11) unless `allowTierChange`; a TODO marker; the envelope exceeds the ceiling |
| runner closeout | `closeout()` → `finalizeRecord` | the envelope exceeds the ceiling |

The measure is the envelope the store would write, serialized exactly as `lib.writeJson` does (indent 1, trailing newline); the self-test checks the measured bytes equal the file on disk at apply and at close. The ceiling is `workflow/check-catalog.json` → `byteCeilings.record` (32,000 bytes for records dated 2026-09-12 or later); a call option overrides it only for tests. On a breach the helper throws `RecordCeilingError` with the id, stage, bytes, ceiling and the catalog remedy, and the record stays as it was: absent, or IN PROGRESS and trimmable. A DONE record over the ceiling can now only be one written outside the helpers, which the validator's `doneOverCeiling` reports.

## Figma helper API

`compose({ fileKey, pages, pageId, pageName, fonts, parent: { id, expect }, components, variables, styles, readOnly, body, limit })` returns the script text: the helpers, then `F.guardFile`, `page`, `F.fonts`, `parent`, `lib`, `vars`, `styles` as the options describe, then the body, then `return { created, readback }` (a body's own `return` shadows it). Over 50,000 characters, the `use_figma` limit, it throws. `readOnly` defaults to the NPVE source file.

| `F.` | Does | Reads back |
|---|---|---|
| `guardFile(fileKey, pages)` | file identity, then the page set by id and name | throws on mismatch |
| `node(id, expect)` | `getNodeByIdAsync` with drift checks on any property | throws on missing or drifted |
| `page(id, expect)` | node check with `type: 'PAGE'`, then `setCurrentPageAsync` | |
| `fonts(list)` | `loadFontAsync` for each | |
| `components / variables / styles(keys)` | keyed imports in the same call | throws by name and key on null or error |
| `paint(variable, rgb)` | `setBoundVariableForPaint` on a SOLID paint | `boundVariables.color.id === variable.id` |
| `bind(node, field, variable)` | `setBoundVariable` | `boundVariables[field].id === variable.id` |
| `frame(parent, o)` | frame or component, appended first, auto-layout, fixed width hugging its primary axis | tracked in `created`; refused in a read-only file |
| `text(parent, o)` | text with an imported style; fonts must be loaded | `characters` equal; tracked; refused in a read-only file |
| `instance(component, parent, o)` | instance appended, named, properties set, resized | via `props`; tracked; refused in a read-only file |
| `props(instance, values)` | `setProperties` by exact exposed names | `componentProperties[k].value` equal (a wrong name is ignored by Figma, so it fails here) |
| `integer(node)` | rule 4 | throws on fractional width or height |
| `snapshot(n)` / `readback(ids)` | id, name, type, parent, key, x, y, width, height, bound variable ids | |
