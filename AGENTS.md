## Rules for any agent working in these files

Any agent — Claude, Codex, or other — editing the Figma files or this repo follows the same loop. Work that skips it gets audited and may be superseded.

The eleven rules are canonical in `workflow/rules.json` → agentRules and appear in every generated `workflow/npve-contract.generated.json`; CLAUDE.md points to the same text. Their titles: 1 Read before touching; 2 Audit before building; 3 One batch at a time; 4 Additive only; 5 No invention; 6 Verify in pixels; 7 Record every batch; 8 Report per rule 13; 9 Stop on disagreement; 10 Record gate; 11 Risk is planner/operator-owned.

For NPVE work: run `node scripts/workflow/validate-workflow.js`, then read the contract, the selected manifest item, and its last record. Read the full aggregate only when routed there. The record store remains the authority; the contract is a freshness-checked projection; chat history is not the record.

The contract includes `workflow/execution-policy.md`: verified mappings before building, visible milestones, bounded recovery, portable checkpoints and plain-language communication. Read that policy directly only if the contract has not supplied it. Planning and execution can stay in this session. These rules apply equally to Copilot, Cline, Claude, Codex and other clients.
